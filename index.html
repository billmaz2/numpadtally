    How the significance test works

    Each test asks: if only chance were at work, how often would a result at least this repetitive turn up? That fraction is the p-value. Small means unlikely to be chance.

    The first two tests use this chance model: every number is picked independently and at random from all 10^N possible numbers. The page simulates that many times with the same amount of numbers as yours, and counts how often the simulated most-frequent number (or the number of equal pairs) is at least as large as yours. The last two tests keep your own numbers and only shuffle their order at random, then ask how often a run of 2 (or 3) numbers repeats as many times as yours did. That separates “you favour certain numbers” from “you type certain numbers in a certain order”.

    Four tests are run at once, which makes a lucky hit more likely, so each p-value is multiplied by the number of tests (capped at 1) to give the adjusted p. A result is called significant when the adjusted p is below 0.05. Significant means more repetitive than random picking, not why. People are not random number generators, so rounds with lots of numbers will often show it. With only a handful of numbers the tests have little power, and a “not significant” result does not prove there is no pattern.

    How patterns are found

    The numbers are read in the order you typed them. A sliding window moves one number at a time and takes every run of 2 numbers, then every run of 3. Identical runs are counted (runs may overlap). Runs seen at least twice are patterns. A shorter run is hidden when it only ever appears inside a longer pattern with the same count, so 1234 → 5678 → 9012 is not also listed as its two halves. A loop that repeats (A → B → C, then B → C → A and so on) is listed once, under its most repeated starting point.
